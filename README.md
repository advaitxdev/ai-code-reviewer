# AI Code Reviewer

A website that helps you review your code for syntax errors, best practices, efficiency and helps you write overall cleaner and better code.
Made using React, CSS and the Gemini API (3.5-flash-lite) for reviewing code.

### 🥞 Technologies
- ``` Vite ```
- ``` React.js ```
- ``` Javascript ```
- ``` CSS ```
- ``` Gemini API (3.5-flash-lite) ```
